# Word & Pages — Full Function Reference

2026-09-17 · @Someone

A nested catalog of every function in Microsoft Word and Apple Pages: location, tool category, parameters, presets, core logic, and UI type (menu, button, dialog, gallery). Built as a reference for the Letters spec.

## Word

## Word — File / Backstage

- **New** — Location: File tab, first Backstage pane. Category: document management. Parameters: template choice, search keyword, category filter. Presets: Blank Document, Resume, Cover Letter, Report, Card, and the full Office.com template gallery. Core logic: instantiates a new document from a .dotx template, copying its styles and content controls, opens in a new window. UI: full-screen gallery pane with search box and filter chips.
  - **Template search** — Location: top of New pane. Parameters: keyword, category tag. Core logic: queries Microsoft's online template catalog and returns thumbnails. UI: search box plus filter chips.
  - **Blank Document** — Location: first tile in New pane. Core logic: creates the document from Normal.dotm. UI: tile/button.
- **Open** — Location: File tab, second Backstage pane. Category: document management. Parameters: file path or URL, pinned items. Presets: Recent, This PC, Browse, OneDrive, Add a Place, Recover Unsaved Documents. Core logic: reads .docx/.doc/.rtf/.odt through format filters and loads the XML package into the document model. UI: pane with list plus a Browse button that opens the native OS file dialog.
  - **Recent** — Parameters: pin toggle per item. Core logic: reads the MRU list from the registry or plist. UI: scrollable list with pin icons.
  - **Recover Unsaved Documents** — Core logic: opens the AutoRecover temp folder. UI: link that opens a file dialog pointed at that folder.
- **Info** — Location: File tab, default landing pane. Category: document properties and protection. Core logic: aggregates metadata, protection state, sharing state, and version history into one pane. UI: stacked cards and dropdown buttons.
  - **Protect Document** — Category: security. Parameters: password, editing restrictions, access restrictions, signature. Core logic: sets document-level protection flags in settings.xml and, for passwords, AES-256 encrypts the package. UI: dropdown menu with five sub-actions.
    - **Encrypt with Password** — Parameters: password, confirm password. Core logic: AES-256 encrypts the OOXML package. UI: modal dialog.
    - **Restrict Editing** — Parameters: formatting restriction toggle plus style limiter list, editing restriction dropdown (no changes, comments, tracked changes, filling in forms), exceptions by user. Core logic: writes protection XML and can require a password or user auth to lift it. UI: right-hand task pane, not a simple button.
    - **Mark as Final** — Core logic: sets a read-only flag and shows a banner. UI: single menu item, no dialog.
  - **Inspect Document** — Category: cleanup. Parameters: checkboxes for comments/revisions, document properties/personal info, headers/footers/watermarks, hidden text, custom XML, collapsed headings, embedded documents. Core logic: scans package parts by content type and removes matches per category on request. UI: dialog with checklist, Inspect button, then a results list with per-category Remove buttons.
    - **Check Accessibility** — Core logic: runs rule checks (missing alt text, contrast, reading order, table headers) and groups results as Errors/Warnings/Tips. UI: task pane, live-updating.
    - **Check Compatibility** — Core logic: scans for features unsupported in older Word versions. UI: one-shot modal report.
  - **Manage Document** — Core logic: recover or permanently delete autosaved versions. UI: dropdown with two menu items.
  - **Version History** — Category: collaboration, cloud files only. Core logic: queries the OneDrive/SharePoint version API and lists timestamped snapshots. UI: side pane list; opening one shows a read-only preview with Restore and Compare buttons.
- **Save / Save As** — Location: File tab. Category: document management. Parameters: file name, location, format (.docx, .doc, .pdf, .rtf, .odt, .txt, .dotx), save-thumbnail toggle, embed fonts. Presets: format defaults to .docx. Core logic: Save writes silently to the existing path; Save As opens a picker then serializes the document model to an OOXML zip (or converts through a format filter). UI: Save is a single button (Ctrl+S); Save As is a pane leading to the OS save dialog.
  - **Save as PDF/XPS** — Parameters: Optimize for Standard or Minimum size; Options for page range, markup, non-printing info, PDF/A compliance, bitmap text. Core logic: renders each page through the internal print-to-PDF pipeline. UI: dialog with an Options button.
- **Print** — Location: File tab. Category: output. Parameters: printer, copies, page range mode, one-sided/two-sided, collation, orientation, paper size, margin preset, pages-per-sheet. Presets: margin presets (Normal, Wide, Narrow, Mirrored) and pages-per-sheet options (1, 2, 4, 6, 8, 16). Core logic: paginates the document through the print driver and sends a spool job. UI: pane with a live preview plus stacked dropdown settings.
- **Share** — Location: File tab and top-right ribbon button. Category: collaboration. Parameters: recipient, permission level (can edit/can view), message, link scope (anyone, org, people with access, specific people), expiration, link password. Core logic: uploads the document to OneDrive/SharePoint if it is local, then generates a sharing URL through the cloud API. UI: side pane or modal with Invite People, Copy Link, and Send a Copy tabs.
- **Export** — Location: File tab. Category: output/conversion. Presets: Create PDF/XPS, Change File Type (Document, Template, Word 97-2003, OpenDocument, PDF, Plain Text, Rich Text, Web Page). Core logic: routes through the same serialization pipeline as Save As. UI: pane with two option tiles, each opening a sub-list.
- **Account** — Location: File tab. Category: app settings. Parameters: sign-in identity, background theme, app theme (Colorful, Dark Gray, Black, White), connected services. Core logic: reads and writes the registry/plist identity token. UI: pane with dropdowns and a sign-in button.
- **Options** — Location: File tab, bottom of list. Category: app settings. Parameters: 11 categories (General, Display, Proofing, Save, Language, Ease of Access, Advanced, Customize Ribbon, Quick Access Toolbar, Add-ins, Trust Center). Core logic: writes to the global app preference store, so changes apply across documents, not just the current one. UI: modal dialog, left nav list plus right settings panel.
  - **Proofing** — Parameters: AutoCorrect Options button opening a nested dialog (replace-as-you-type table, math autocorrect, autoformat-as-you-type rules), spelling/grammar toggles, writing style dropdown. UI: settings panel with a nested dialog launcher.
  - **Customize Ribbon** — Parameters: two-pane command list with Add/Remove, New Tab, New Group, Rename, show/hide checkboxes, import/export customization file. Core logic: writes ribbon XML to the user profile. UI: dual-listbox dialog.

## Word — Home Tab

- **Clipboard group** — Location: Home tab, far left. Category: editing.
  - **Paste** — Parameters: split button, top half pastes with default behavior, arrow opens Keep Source Formatting / Merge Formatting / Picture / Keep Text Only, plus a Paste Special dialog (format list: HTML, Unformatted Unicode Text, RTF, Bitmap). Core logic: reads the OS clipboard, reconciles the source's style runs against the destination's style table per the chosen merge rule. UI: split button with dropdown gallery.
  - **Cut / Copy** — Core logic: serializes the selected range (text plus formatting) to the clipboard in multiple formats simultaneously. UI: plain buttons.
  - **Format Painter** — Parameters: single-use click, double-click for multi-use (stays active until Esc). Core logic: copies the run/paragraph-level formatting properties of the source selection and applies them to the next selection made. UI: toggle button.
- **Font group** — Category: character formatting.
  - **Font Name / Font Size** — Parameters: live-preview dropdown list, direct type-in. Core logic: sets the run property rFonts/sz in the OOXML run; live preview temporarily re-renders the selection on hover. UI: combo box (editable dropdown).
  - **Grow / Shrink Font** — Core logic: steps through the standard size ramp. UI: buttons.
  - **Change Case** — Presets: Sentence case, lowercase, UPPERCASE, Capitalize Each Word, tOGGLE cASE. Core logic: rewrites the literal characters of the run (not just a display property). UI: dropdown menu.
  - **Clear Formatting** — Core logic: strips direct run and paragraph formatting back to the applied style's defaults. UI: button.
  - **Bold / Italic / Underline** — Parameters: Underline has a dropdown for line style (single, double, thick, dotted, dashed, wave) and underline color. Core logic: toggles the corresponding run property. UI: toggle buttons; Underline is a split button.
  - **Strikethrough / Subscript / Superscript** — Core logic: toggles run properties; sub/superscript also adjusts baseline offset and auto-shrinks size. UI: toggle buttons.
  - **Text Effects and Typography** — Presets: an outline/shadow/reflection/glow preset gallery, plus separate Outline, Shadow, Reflection, Glow, and Ligatures sub-menus. Core logic: applies WordArt-style text effect XML to the run. UI: gallery dropdown.
  - **Text Highlight Color** — Parameters: 15-color grid, painter-mode toggle (click then drag across multiple selections), No Color. Core logic: sets the run's highlight property. UI: split button with color grid.
  - **Font Color** — Parameters: theme color row (10 colors x 5 tint/shade variants), standard color row, Automatic, More Colors (opens RGB/HSL picker), gradient sub-gallery. Core logic: sets the run color property, theme colors store a reference so they update if the theme changes. UI: split button with grid.
  - **Font dialog launcher** — Opens the full Font dialog. Parameters, Font tab: font, style, size, font color, underline style, underline color, effects checkboxes (strikethrough, double strikethrough, superscript, subscript, small caps, all caps, hidden). Advanced tab: character scale percentage, spacing (expanded/condensed by points), position (raised/lowered by points), kerning-for-fonts-above-size checkbox, OpenType features (ligatures, number spacing, number forms, stylistic sets). Core logic: batch-writes every checked run property at once. UI: modal dialog, two tabs.
- **Paragraph group** — Category: paragraph formatting.
  - **Bullets / Numbering / Multilevel List** — Parameters: library gallery of preset styles, Define New Bullet/Number Format dialog (symbol picker or image for bullets; number format string, font, alignment for numbering), list level (Tab/Shift-Tab), Set Numbering Value. Core logic: attaches the paragraph to a numbering definition part (numbering.xml) referencing an abstract list and level. UI: split button with gallery dropdown.
  - **Decrease / Increase Indent** — Core logic: steps the paragraph's left indent by one default tab stop. UI: buttons.
  - **Sort** — Parameters: sort by up to 3 keys (paragraph/field/heading), type (text/number/date), ascending/descending, header row toggle. Core logic: reorders paragraphs or table rows by the chosen key. UI: modal dialog.
  - **Show/Hide paragraph marks** — Core logic: toggles rendering of formatting marks (pilcrows, spaces, tabs) without changing content. UI: toggle button.
  - **Align Left / Center / Align Right / Justify** — Core logic: sets paragraph jc property. UI: toggle buttons, mutually exclusive.
  - **Line and Paragraph Spacing** — Parameters: line spacing presets (1.0 to 3.0), Add/Remove Space Before or After Paragraph, Line Spacing Options (opens Paragraph dialog). Core logic: sets line rule and spacing properties. UI: split button.
  - **Shading** — Parameters: same color grid as Font Color. Core logic: sets paragraph or cell background fill. UI: split button.
  - **Borders** — Presets: gallery of border combinations (bottom, top, left, right, all, outside, inside, no border), Borders and Shading dialog (setting: box/shadow/3D/custom, style/color/width per edge, art borders, apply-to scope). Core logic: writes paragraph or table border properties. UI: split button with a dialog launcher at the bottom of the dropdown.
  - **Paragraph dialog launcher** — Parameters, Indents and Spacing tab: alignment, outline level, indent before/after/first-line or hanging with amount, spacing before/after, line spacing, don't-add-space-between-paragraphs-of-same-style checkbox. Line and Page Breaks tab: widow/orphan control, keep with next, keep lines together, page break before, suppress line numbers, don't hyphenate. Core logic: batch-writes paragraph properties (pPr). UI: modal dialog, two tabs.
- **Styles group** — Category: style management. Parameters: quick-style gallery thumbnails (Normal, No Spacing, Heading 1-9, Title, Subtitle, Quote, List Paragraph, etc.), live preview on hover. Core logic: applies a named style reference to the paragraph or run, pulling its formatting from styles.xml; also exposes Create a Style, Clear Formatting, and Apply Styles (type-ahead box). UI: gallery strip with a dialog-launcher arrow opening the full Styles task pane (list with New Style, Style Inspector, Manage Styles buttons).
- **Editing group** — Category: navigation and find.
  - **Find** — Parameters: inline search box in Navigation Pane, or classic Find dialog with Match Case/Whole Words/Wildcards/Sounds Like/Find All Word Forms, Format and Special (tab, paragraph mark, etc.) pickers. Core logic: runs a text/regex-like scan over the document's run text, highlighting all matches and populating the Navigation Pane's Results tab. UI: opens the Navigation task pane on the left.
  - **Replace** — Parameters: Find what, Replace with, Replace/Replace All/Find Next buttons, same Format and Special option pickers. Core logic: same scan as Find, substitutes matched ranges preserving or overwriting formatting per settings. UI: modal dialog.
  - **Go To** — Parameters: target type (Page, Section, Line, Bookmark, Comment, Footnote, Endnote, Field, Table, Graphic, Equation, Object, Heading), value/number. Core logic: resolves the target to a document position and scrolls/selects it. UI: tab inside the Find and Replace dialog.
  - **Select** — Presets: Select All, Select Objects, Select All Text with Similar Formatting, Selection Pane (lists floating objects with show/hide eye icons and reorder). Core logic: builds a selection range or opens the object-management pane. UI: dropdown menu.

## Word — Insert Tab

- **Pages group** — Category: page structure.
  - **Cover Page** — Parameters: gallery of preset layouts with placeholder content controls (title, subtitle, date, author). Core logic: inserts a section break then a formatted first page bound to document properties (title/author autofill from metadata). UI: gallery dropdown.
  - **Blank Page** — Core logic: inserts two page breaks with an empty paragraph between them. UI: button.
  - **Page Break** — Core logic: inserts a hard page-break character forcing the next content to a new page. UI: button.
- **Tables group** — Category: structured content.
  - **Insert Table** — Parameters: grid picker (drag to choose rows x columns, live preview), Insert Table dialog (exact row/column count, AutoFit behavior: fixed/content/window), Draw Table (freehand pen), Convert Text to Table (delimiter: paragraph/comma/tab/other), Excel Spreadsheet (embeds an OLE object), Quick Tables gallery (preset styled tables like calendars). Core logic: creates a table part in the document tree with a default table style reference. UI: split button with a grid picker as the primary surface.
- **Illustrations group** — Category: media and graphics.
  - **Pictures** — Parameters: source picker (This Device, Stock Images, Online Pictures search). Core logic: embeds the image binary in the media folder of the package and inserts a drawing anchor (inline or floating). UI: split button.
  - **Shapes** — Parameters: category flyout (lines, rectangles, basic shapes, arrows, equation shapes, flowchart, stars/banners, callouts), draw-then-size interaction. Core logic: inserts a DrawingML shape with default theme fill/outline. UI: gallery dropdown, then canvas draw.
  - **Icons** — Parameters: searchable category gallery of vector icons. Core logic: inserts as an editable vector graphic (recolorable, convertible to shape). UI: modal gallery dialog.
  - **3D Models** — Parameters: source picker (device, stock 3D). Core logic: embeds a model file with a 3D viewport control for rotation. UI: split button.
  - **SmartArt** — Parameters: category list (List, Process, Cycle, Hierarchy, Relationship, Matrix, Pyramid, Picture) with layout gallery per category. Core logic: inserts a diagram graphic bound to a structured text pane (bullet list drives node count/labels automatically). UI: modal gallery dialog, then an editable text pane alongside the diagram.
  - **Chart** — Parameters: chart type gallery (Column, Line, Pie, Bar, Area, Scatter, Map, Stock, Surface, Radar, Treemap, Sunburst, Histogram, Box & Whisker, Waterfall, Funnel, Combo) with sub-type variants. Core logic: inserts a chart object bound to an embedded Excel worksheet data source. UI: modal dialog with left category list and right variant gallery.
  - **Screenshot** — Parameters: thumbnails of open windows, Screen Clipping (drag-select region). Core logic: captures a bitmap and inserts as a picture. UI: gallery dropdown.
- **Add-ins group** — Category: extensibility. **Get Add-ins** opens the Office Store; installed add-ins appear as buttons that launch a task pane running sandboxed JS/HTML.
- **Media group** — **Online Video**, parameters: paste embed code or search; core logic: inserts an iframe-like video placeholder that streams from the source on play. UI: dialog with a URL/search field.
- **Links group** — Category: navigation.
  - **Link (Hyperlink)** — Parameters: target type tabs (Existing File/Web Page, Place in This Document, Create New Document, E-mail Address), text to display, ScreenTip button. Core logic: wraps the selection in a hyperlink relationship pointing to the target URL/bookmark. UI: modal dialog.
  - **Bookmark** — Parameters: name (no spaces), list of existing bookmarks with Go To/Delete. Core logic: tags a range with a named bookmark anchor usable by cross-references and hyperlinks. UI: modal dialog.
  - **Cross-reference** — Parameters: reference type dropdown (Numbered Item, Heading, Bookmark, Footnote, Endnote, Equation, Figure, Table), insert-reference-to dropdown (text, page number, above/below), insert-as-hyperlink checkbox. Core logic: inserts a REF field that resolves and auto-updates against the target. UI: modal dialog.
- **Comments group** — **New Comment**, core logic: anchors a threaded comment to the current selection, stored in a separate comments part linked by range id. UI: button opening an inline comment bubble.
- **Header & Footer group** — Category: page furniture.
  - **Header / Footer** — Parameters: preset gallery (Blank, Blank Three Column, Alphabet, Banded, etc. with placeholder content controls), Edit Header/Footer (enters a dedicated editing region), Remove Header/Footer. Core logic: creates a header/footer part linked to the section; different-first-page and different-odd-even are section-level toggles exposed in the contextual Header & Footer Design tab. UI: split button with gallery.
  - **Page Number** — Parameters: position submenu (Top/Bottom/Margins/Current Position) each with a style gallery, Format Page Numbers dialog (number format, include chapter number, start-at value). Core logic: inserts a PAGE field, optionally with section-scoped restart numbering. UI: nested dropdown menus.
- **Text group** — Category: text objects.
  - **Text Box** — Parameters: preset gallery (Simple, Austin, Ion, etc.) or Draw Text Box freehand. Core logic: inserts a floating DrawingML text-frame shape independent of body text flow. UI: split button.
  - **Quick Parts** — Presets: Document Property fields (Author, Title, Company, etc.), Field (100+ field codes like DATE, PAGE, REF, IF, MERGEFIELD, grouped by category), Building Blocks Organizer (browsable gallery of all AutoText/cover pages/headers with preview and Insert/Delete/Edit Properties), Save Selection to Quick Part Gallery. Core logic: Building Blocks are stored as reusable XML fragments in a global template, inserted by reference then expanded. UI: dropdown menu leading to sub-dialogs.
  - **WordArt** — Parameters: preset style gallery (fill/outline/effect combinations). Core logic: inserts a text box pre-loaded with a text-effect style applied. UI: gallery dropdown.
  - **Drop Cap** — Parameters: None / Dropped / In Margin, Drop Cap dialog (font, lines to drop, distance from text). Core logic: converts the first letter/word into a floating frame scaled to span N lines. UI: gallery dropdown with a dialog launcher.
  - **Signature Line** — Parameters: signer name/title/email, instructions text, allow-comments-in-signature checkbox, show-sign-date checkbox. Core logic: inserts a Microsoft Office signature provider object bound to a digital certificate at signing time. UI: modal dialog.
  - **Date & Time** — Parameters: format list, Update Automatically checkbox. Core logic: static text or a DATE field depending on the checkbox. UI: modal dialog.
  - **Object** — Parameters: Create New (object type list from installed OLE servers) or Create from File (path, Link to file checkbox, Display as icon checkbox). Core logic: embeds or links an OLE object rendered via its native application. UI: modal dialog, two tabs.
- **Symbols group** — **Equation**, parameters: built-in equation gallery or blank canvas with a contextual Equation tab (symbol palette, structures: fraction/script/radical/integral/matrix); core logic: renders OMML markup with live layout. UI: split button plus dedicated authoring canvas. **Symbol**, parameters: recently-used strip, More Symbols dialog with font/subset picker and character code entry; core logic: inserts a single Unicode character/glyph. UI: split button with a grid dialog.

## Word — Design & Layout Tabs

- **Design tab — Document Formatting group** — Category: theming.
  - **Themes** — Parameters: gallery of built-in themes, Browse for Themes, Save Current Theme. Core logic: swaps the theme part (theme1.xml: color scheme, font scheme, effect scheme) that every theme-linked color/font in the document references, so the whole document restyles without touching direct formatting. UI: gallery dropdown.
  - **Style Set** — Parameters: gallery of paragraph-style bundles (Basic, Casual, Centered, Lines, etc.). Core logic: swaps the mapping from style names to their formatting definitions in styles.xml. UI: gallery strip.
  - **Colors / Fonts / Paragraph Spacing / Effects** — Parameters: each opens its own gallery (color palettes, heading/body font pairs, spacing presets like Compact/Tight/Open/Relaxed, shape-effect sets) plus a Customize option at the bottom. Core logic: edits one slice of the theme part independently. UI: dropdown galleries.
  - **Set as Default** — Core logic: writes the current theme/style-set combination into Normal.dotm so new documents start with it. UI: button.
- **Design tab — Page Background group** — Category: page decoration.
  - **Watermark** — Parameters: preset gallery (Confidential, Draft, Do Not Copy, Urgent), Custom Watermark dialog (picture watermark with scale/washout, or text watermark with font/size/color/layout diagonal-or-horizontal), Remove Watermark. Core logic: inserts a floating header-anchored shape behind text on every page of the section. UI: gallery dropdown with dialog launcher.
  - **Page Color** — Parameters: color grid, Fill Effects (gradient/texture/pattern/picture). Core logic: sets the section's page background fill (screen/print visibility depends on Options > Display > Print Background Colors). UI: split button.
  - **Page Borders** — Parameters: same Borders and Shading dialog as paragraph borders, plus Art dropdown for decorative border graphics and Options for margin-relative offset. Core logic: writes a page-level border definition (pgBorders) to the section properties. UI: button opening a dialog.
- **Layout tab — Page Setup group** — Category: page geometry.
  - **Margins** — Parameters: preset gallery (Normal, Narrow, Moderate, Wide, Mirrored) plus Custom Margins opening the Page Setup dialog. Core logic: sets section-level margin properties (top/bottom/left/right, gutter, gutter position). UI: gallery dropdown.
  - **Orientation** — Presets: Portrait, Landscape. Core logic: swaps page width/height and re-flows content. UI: dropdown.
  - **Size** — Presets: Letter, Legal, A4, A3, A5, Executive, etc., plus More Paper Sizes for custom width/height. Core logic: sets section page size. UI: gallery dropdown.
  - **Columns** — Presets: One, Two, Three, Left, Right, plus More Columns dialog (number of columns, width and spacing per column, equal-column-width checkbox, line-between checkbox, apply-to scope). Core logic: sets section column definition, causing text to flow column-to-column before advancing pages. UI: gallery dropdown with dialog launcher.
  - **Breaks** — Presets: Page, Column, Text Wrapping (breaks), Section Break Next Page/Continuous/Even Page/Odd Page. Core logic: inserts the corresponding break character; section breaks create a new set of independently-configurable page properties. UI: dropdown menu.
  - **Line Numbers** — Presets: None, Continuous, Restart Each Page, Restart Each Section, Suppress for Current Paragraph, Line Numbering Options dialog (start at, count by, distance from text, restart mode). Core logic: sets section line-numbering properties, rendered as a computed margin annotation, not literal characters. UI: dropdown menu.
  - **Hyphenation** — Presets: None, Automatic, Manual (walks through candidate breaks for confirmation), Hyphenation Options dialog (hyphenate words in caps checkbox, hyphenation zone, limit consecutive hyphens). Core logic: enables the line-breaking engine to split words at soft hyphen points computed from the language dictionary. UI: dropdown menu.
- **Layout tab — Paragraph group** — Duplicates Indent Left/Right and Spacing Before/After as direct numeric steppers for quick access, writing the same paragraph properties as the Home tab's Paragraph dialog.
- **Layout tab — Arrange group** — Category: object placement, active when a floating object is selected.
  - **Position** — Presets: a 3x3 grid of page-relative placements (with text wrapping applied automatically), plus More Layout Options. Core logic: sets the anchor's horizontal/vertical alignment relative to margin/page/column. UI: gallery dropdown.
  - **Wrap Text** — Presets: In Line with Text, Square, Tight, Through, Top and Bottom, Behind Text, In Front of Text, Edit Wrap Points. Core logic: sets the drawing's wrap type and, for Edit Wrap Points, lets the user drag a custom polygon that text will flow around. UI: dropdown menu, then canvas handles for Edit Wrap Points.
  - **Bring Forward / Send Backward** — Presets: one step, Bring to Front/Send to Back, Bring in Front of Text/Send Behind Text. Core logic: reorders the object's z-index among overlapping drawings. UI: split buttons.
  - **Align** — Presets: Align Left/Center/Right/Top/Middle/Bottom, Distribute Horizontally/Vertically, Align to Page/Margin/Selected Objects, Use Alignment Guides toggle. Core logic: recalculates object offsets relative to the chosen reference frame. UI: dropdown menu.
  - **Group / Ungroup** — Core logic: wraps multiple selected shapes in a single group transform so they move/resize together. UI: buttons.
  - **Rotate** — Presets: 90° Right/Left, Flip Vertical/Horizontal, More Rotation Options (exact angle). Core logic: sets the shape's rotation transform. UI: dropdown menu.

## Word — References Tab

- **Table of Contents group** — Category: navigation aids.
  - **Table of Contents** — Parameters: built-in preset gallery (Automatic Table 1/2, Manual Table), Custom Table of Contents dialog (show levels 1-9, show page numbers, right-align page numbers, tab leader style, format from a template list, Options button to remap which styles count as which TOC level). Core logic: scans paragraphs for the mapped heading styles and inserts a TOC field that compiles a hyperlinked, page-numbered entry list. UI: split button with gallery and dialog launcher.
  - **Add Text** — Presets: Do Not Show in Table of Contents, Level 1/2/3. Core logic: sets the paragraph's outline level or applies a TOC-mapped style without changing visible formatting. UI: dropdown menu.
  - **Update Table** — Presets: Update page numbers only, Update entire table. Core logic: re-scans the document and rebuilds the TOC field's cached result. UI: button, also right-click on the TOC.
- **Footnotes group** — Category: annotations.
  - **Insert Footnote / Insert Endnote** — Core logic: inserts a reference mark in the body and a corresponding note in the footnote/endnote part, auto-numbered. UI: buttons.
  - **Next Footnote** — Presets: dropdown to jump between Next/Previous Footnote or Endnote. UI: split button.
  - **Show Notes** — Core logic: scrolls to and highlights the notes pane/area. UI: button.
  - **Footnote & Endnote dialog launcher** — Parameters: location (bottom of page/below text, end of section/document), number format (1,2,3 / a,b,c / i,ii,iii / symbol), custom mark, start-at value, numbering scope (continuous, restart each section, restart each page), Convert button (swap footnotes and endnotes). Core logic: writes the note-numbering configuration for the section. UI: modal dialog.
- **Citations & Bibliography group** — Category: research.
  - **Insert Citation** — Parameters: Add New Source (dialog: source type dropdown - Book, Journal Article, Website, etc., changes the field set shown - author, title, year, publisher...), Add New Placeholder, search box over existing sources. Core logic: inserts a CITATION field referencing an entry in the document's source XML, rendered per the active style. UI: split button with a searchable dropdown.
  - **Manage Sources** — Parameters: Master List / Current List dual panes, Search box, Sort by (Author/Title/Year/Tag), Copy/Delete/Edit/New buttons, Browse to open another master list file. Core logic: reconciles the document's local source list against a global master list stored per user. UI: modal dialog.
  - **Style** — Presets: APA, MLA, Chicago, IEEE, GB7714, ISO 690, Turabian, and others. Core logic: swaps the XSLT-like style sheet used to render every CITATION and Bibliography field, so switching styles reflows all existing citations. UI: dropdown.
  - **Bibliography** — Presets: Bibliography, References, Works Cited, Insert Bibliography (unformatted). Core logic: inserts a field that compiles every source used in the document into a formatted, alphabetized list per the active style. UI: gallery dropdown.
- **Captions group** — Category: figure/table labeling.
  - **Insert Caption** — Parameters: label dropdown (Figure, Table, Equation, or New Label), position (above/below selected item), numbering button (format, include chapter number). Core logic: inserts a SEQ field that auto-numbers within its label category, tied to the object it's attached to. UI: modal dialog.
  - **Insert Table of Figures** — Parameters: caption label to compile, show page numbers, right-align page numbers, tab leader, format, include label and number checkbox. Core logic: scans the document for SEQ fields of the chosen label and compiles a page-numbered list, mirroring the TOC mechanism. UI: modal dialog.
  - **Cross-reference** — Same mechanism as Insert tab's Cross-reference, surfaced here for figure/table/equation targets specifically.
- **Index group** — Category: back-matter.
  - **Mark Entry** — Parameters: main entry text, subentry text, cross-reference option, page-range options (current page, bookmark range), format (bold/italic checkboxes), Mark vs Mark All. Core logic: inserts a hidden XE field at the marked location. UI: non-modal dialog that stays open while the user continues selecting text.

Core logic: parses the external file and populates a new table's grid, preserving Pages' own formula syntax for any recognized formulas. UI: File > Insert from the toolbar's Table dropdown, or drag-and-drop onto the canvas.

## Pages — Review, Collaboration & View Menu

- **Comments** — Location: toolbar button or Insert > Comment. Category: feedback. Parameters: comment text, resolve/reopen toggle, reply thread. Core logic: anchors a threaded comment object to a text range, stored alongside the document content and synced live during collaboration. UI: floating bubble anchored in the margin.
- **Track Changes (Edit > Track Changes, or the Track Changes toolbar toggle)** — Parameters: on/off toggle, per-author color coding (automatic, one color per collaborator). Core logic: wraps insertions/deletions in change-tracking markers carrying author and timestamp, equivalent to Word's ins/del tags. UI: toggle button, changes render as colored underline/strikethrough inline by default.
  - **Review changes** — Presets: Accept/Reject this change, Accept/Reject All. Core logic: same merge-or-discard logic as Word. UI: buttons in a floating change bubble or the Changes pane.
  - **Markup view options** — Presets: Show Changes inline vs Show Changes in margin (bubbles), Show Changes list (a dedicated pane listing every change with jump-to links). UI: View menu submenu.
- **Highlight (separate from Track Changes)** — Parameters: color picker. Core logic: applies a persistent highlight run property, independent of the tracked-change layer, meant to stay after changes are accepted. UI: Format sidebar swatch or right-click menu.
- **Collaborate (live co-authoring)** — Parameters: participant avatars with live cursor colors, @mention in comments to notify a specific collaborator, Share Options (same access/permission/password controls as the toolbar Share button), Stop Sharing. Core logic: syncs the document's operational-transform change log across participants' sessions in near real time over iCloud. UI: avatar stack in the toolbar plus a Collaborate popover.
- **Word Count (View menu or status bar)** — Parameters: scope (document/selection), reports words/characters/paragraphs, optional live display pinned in the status bar. Core logic: tallies the text model, same as Word's Word Count. UI: popover or persistent status-bar readout.
- **Spelling and Grammar (Edit menu)** — Parameters: Check Document Now (jumps issue to issue with a correction popover and Ignore/Learn Spelling options), Check Spelling While Typing toggle, Check Grammar With Spelling toggle. Core logic: runs the OS-level spell/grammar checker over the text model, same engine used system-wide on the Mac. UI: menu toggles plus inline red/green squiggle underlines.
- **View menu (window-level, distinct from the toolbar View button)** — Presets: Show Ruler, Show Word Count, Show Invisibles (formatting marks), Show Layout (margin/column guides), Page Thumbnails, Full Screen, enter/exit Page View vs a continuous-scroll mode. Core logic: toggles chrome and rendering-aid visibility without touching content. UI: menu bar dropdown, several items mirrored as toolbar buttons.
- **Zoom (bottom-left of window, or View menu)** — Parameters: percentage stepper, Fit Width, Fit Page presets. Core logic: scales the rendering surface. UI: dropdown/slider control.
- **Version Browser (File > Revert To > Browse All Versions)** — Parameters: a Time Machine-style stacked-window timeline, Restore button per snapshot. Core logic: reads macOS's document-versioning store (separate from iCloud's live collaboration log) and lets the user preview and roll back to an earlier autosaved state. UI: full-screen version-comparison view.

## Wishlist — Functions People Ask For But Don't Get

### Word — asked for, still refused or ignored

- **True regex in Find & Replace** — Where it would sit: Home tab, Editing group, inside the Find and Replace dialog. What people ask for: real regular-expression syntax (capture groups, lookaheads, character classes) instead of Word's own limited wildcard language. Status: requested since the early 2000s; a Word MVP on Microsoft's own Tech Community confirmed in 2023 that the fix is still "use a Wildcard replace," not real regex, and the underlying back-reference bug in wildcard mode had sat unfixed for months. [Microsoft Tech Community](https://techcommunity.microsoft.com/discussions/word/ms-word-findreplace-back-reference-is-messed-up/3809989/replies/3810160) Why it stays out: the wildcard engine is shared code with Mail Merge Rules and REF fields, so swapping it risks breaking those. UI it would take: an "Use Regular Expressions" checkbox next to the existing "Use Wildcards" one.
- **Real branching version history** — Where it would sit: Info pane, Version History. What people ask for: named branches or the ability to fork a document at a point in time, instead of one linear snapshot list. Status: a recurring request on Microsoft's feedback portal, no roadmap commitment. Why it stays out: OneDrive/SharePoint versioning is linear by design. UI it would take: a tree view added to the existing side pane.
- **A first-class citation manager** — What people ask for: Zotero/EndNote-level source management built into Word itself, since most academic users route around the current Manage Sources dialog with a third-party add-in anyway. Status: not refused so much as stagnant, no material overhaul in over a decade. UI it would take: an expanded Citations & Bibliography group with a real library browser instead of the current flat list.
- **True multi-user paragraph-level merge** — What people ask for: co-authoring that resolves two people editing the same sentence without one save silently overwriting the other. Status: a common complaint in IT admin and Reddit communities, treated by Microsoft as an edge case rather than a bug. Why it stays out: OOXML's diff model wasn't built for operational-transform-style merging the way newer web-native formats are.

### Pages — asked for, explicitly declined or left to die

- **Open citation/bibliography plugin support** — Where it would sit: Insert menu, beside the existing EndNote-only citation item. What people ask for: the same plugin access Zotero has built for Word and LibreOffice. Status: explicitly declined. The Zotero team has said plainly that Apple has never opened a plugin API for Pages, and that EndNote is, and has been since at least 2009, the only citation tool Apple allows in; as of Zotero's own forum in 2021 that still hadn't changed. [Zotero Forums](https://forums.zotero.org/discussion/comment/213357) Why it stays out: Apple built the EndNote hook as a closed, undocumented integration, so there's nothing third parties can build against. UI it would take: a plugin-manager pane, the way Word or Chrome list extensions.
- **Macro or scripting automation** — Where it would sit: would need a new Automation menu, there isn't one today. What people ask for: something like Word's VBA, or even the level of AppleScript support Pages had before version 5. Status: a longtime AppleScript author documented on MacScripter that Pages has been "a dead duck scriptingwise ever since version 5," having lost most of its automation hooks starting around 2013, and Apple's own support community reiterates that Pages simply has no macro support, by design. [MacScripter](https://www.macscripter.net/t/is-it-fair-to-say-that-applescript-is-dead-on-apple-pages/71598) Why it stays out: Apple positions Pages as a consumer app, not a Word competitor on power-user features. UI it would take: a Record Macro button plus a script editor, mirroring Word's Macros group.
- **Pages for Windows** — What people ask for: a native Windows build, or at least a fully-featured web app, so mixed Mac and Windows teams can co-edit without exporting to Word first. Status: requested for over a decade, no response beyond the existing lightweight iCloud web version. Why it stays out: Pages functions as an iCloud/Apple-ecosystem retention feature, a first-class Windows version would work against that.
- **A proper master-page system** — What people ask for: InDesign-style master pages that drive headers, footers, and placeholder regions across many documents at once, not just within one document's own sections. Status: a recurring ask through Apple's own Pages feedback form, no public roadmap response. Why it stays out: Pages' whole-document model doesn't separate a page template from the document using it, this would need real architectural change, not a new menu.

### What this suggests for Letters

The two clearest openings are a citation system nobody has to fight a closed plugin to use, which is already the plan, and true regex-capable Find & Replace, which neither incumbent offers despite two decades of asking.
